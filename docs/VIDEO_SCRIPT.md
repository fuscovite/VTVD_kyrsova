# Сценарій відеопрезентації (4–5 хвилин)

1. **0:00–0:30.** Покажіть головну сторінку і коротко назвіть призначення застосунку — онлайн-запис на послуги СТО та перегляд каталогу OEM-запчастин.
2. **0:30–1:20.** Відкрийте «Послуги» і «Запчастини», зверніть увагу на адаптивний інтерфейс Blade + Bootstrap та дані із бази.
3. **1:20–2:10.** Заповніть форму заявки валідними даними. Покажіть повідомлення про успішне створення.
4. **2:10–2:55.** Введіть некоректний номер телефону. Покажіть серверне повідомлення про помилку; поясніть, що форма містить CSRF-токен Laravel.
5. **2:55–3:45.** Відкрийте адресу адміністративних заявок у приватному вікні або вийдіть із системи. Покажіть перенаправлення на сторінку входу. Увійдіть і продемонструйте створену заявку.
6. **3:45–4:30.** Покажіть папку `database/migrations`, `database/seeders`, `.env.example`, README та команду `php artisan test` з результатом тестів.
7. **4:30–5:00.** Відкрийте GitHub-репозиторій і підсумуйте: Laravel, Blade + Bootstrap, міграції, тестові дані, авторизація, валідація та CSRF.
